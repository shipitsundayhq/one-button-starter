# One-Button Starter (ShipIt Sunday Challenge #1)

Blank single-file browser game template for [ShipIt Sunday Challenge #1](https://shipitsundayhq.github.io/challenges/01-one-button/).

## Use it
1. Download or clone this repo.
2. Open `index.html` in a browser (no build step).
3. Paste the starter prompt from the challenge page into your AI coding tool and attach this file.
4. Ship a live link by Sunday 11:59pm PT.

## Controls
Space, click, or tap only.
